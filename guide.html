STARTER GUIDE

Mulai
bermain.

Ikuti urutan ini untuk memasang connection pack dan masuk ke realm lokal PW155.

01

Siapkan client

Gunakan client lengkap Perfect World 1.5.5 EN. Connection pack bukan pengganti client lengkap.

02

Unduh paket

Ambil PW155 Indonesia Connection Pack, lalu tutup client dan patcher sebelum melanjutkan.

03

Ekstrak ke folder utama

Backup element\interfaces.pck, kemudian ekstrak seluruh isi ZIP ke folder utama client. Izinkan penggantian file.

04

Periksa server

Nyalakan VM dan service PW155. Buka portal ini dan pastikan status realm online serta ping server berwarna hijau.

05

Buat akun dan masuk

Buat akun di portal, jalankan START-PW155.cmd, pilih Local PW155, lalu buat karakter. Area awal adalah Celestial Vale.

TROUBLESHOOTING

Jika belum bisa masuk

Server network error

Pastikan VM hidup, port forwarding aktif, dan realm berstatus online di portal.

Incorrect username or password

Gunakan username dan sandi akun game yang dibuat dari portal, bukan kredensial VM.

Could not login to server

Map karakter mungkin belum aktif. Untuk karakter awal, pastikan instance Celestial Vale (is61) online.
