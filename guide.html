PANDUAN PEMAIN

Mulai
bermain.

Ikuti langkah berikut untuk memasuki dunia PWKU. Menu, quest, skill, dan item di dalam game saat ini menggunakan bahasa Inggris.

01

Siapkan game

Gunakan client lengkap Perfect World 1.5.5 berbahasa Inggris.

02

Unduh paket PWKU

Ambil Paket Koneksi PWKU, lalu tutup game dan launcher sebelum melanjutkan.

03

Pasang paket

Simpan salinan folder game terlebih dahulu, kemudian ekstrak seluruh isi paket ke folder utama game.

04

Periksa status

Buka portal dan pastikan status server menunjukkan Online.

05

Buat akun dan masuk

Buat akun di portal, jalankan launcher PWKU, lalu buat karakter dan mulai petualangan di Celestial Vale.

BANTUAN

Jika belum bisa masuk

Tidak dapat terhubung

Pastikan internet aktif dan status server di portal menunjukkan Online.

Username atau sandi salah

Gunakan username dan sandi akun yang dibuat melalui portal PWKU.

Belum bisa masuk ke dunia

Tunggu beberapa saat, periksa pengumuman terbaru, lalu coba masuk kembali. Hubungi admin jika kendala tetap terjadi.
