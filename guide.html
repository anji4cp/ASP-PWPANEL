STARTER GUIDE

Mulai
bermain.

Ikuti urutan ini untuk menghubungkan client Perfect World 1.5.5 EN ke realm PWKU. Menu, tombol, quest, skill, dan item di dalam client saat ini tetap menggunakan bahasa Inggris.

01

Siapkan client

Gunakan client lengkap Perfect World 1.5.5 EN. Connection pack bukan pengganti client lengkap.

02

Unduh paket koneksi

Ambil PWKU Connection Pack untuk Client EN, lalu tutup client dan patcher sebelum melanjutkan. Paket ini mengatur koneksi; paket ini bukan terjemahan penuh bahasa Indonesia.

03

Ekstrak ke folder utama

Buat backup folder client, kemudian ekstrak seluruh isi ZIP ke folder utama client. Izinkan penggantian file yang termasuk dalam paket.

04

Periksa server

Buka portal dan pastikan status server Online. Gateway publik yang digunakan client adalah game.pwku.cloud:29000.

05

Buat akun dan masuk

Buat akun di portal, jalankan launcher dari paket PWKU, pilih server PWKU, lalu buat karakter. Area awal adalah Celestial Vale.

TROUBLESHOOTING

Jika belum bisa masuk

Server network error

Pastikan internet aktif, status server Online, dan koneksi ke game.pwku.cloud:29000 tidak diblokir firewall.

Incorrect username or password

Gunakan username dan sandi akun game yang dibuat dari portal, bukan kredensial VM.

Could not login to server

Map karakter mungkin belum aktif. Untuk karakter awal, pastikan instance Celestial Vale (is61) online.
